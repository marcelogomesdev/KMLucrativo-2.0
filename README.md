## 📖 Sobre o Projeto

O **KM Lucrativo 2.0** é uma aplicação web desenvolvida para ajudar motoristas de aplicativo a acompanharem de forma clara e estratégica os resultados financeiros e operacionais da atividade.

A plataforma permite registrar corridas, controlar receitas e despesas, acompanhar metas, analisar indicadores, calcular custos reais do veículo e identificar oportunidades para aumentar a lucratividade.

A aplicação funciona diretamente no navegador, não exige backend e mantém todas as informações armazenadas localmente no dispositivo do usuário.

O projeto foi desenvolvido com foco em:

* Controle financeiro;
* Análise de dados;
* Tomada de decisão;
* Produtividade;
* Privacidade;
* Acessibilidade;
* Experiência do usuário.

## 🚀 Como Executar

### 🌐 Acessar Online

O projeto está publicado no GitHub Pages e pode ser utilizado diretamente pelo navegador:

<p align="center">
  <a href="https://marcelogomesdev.github.io/KMLucrativo-2.0/">
    <strong>🌐 Acessar o KM Lucrativo 2.0</strong>
  </a>
</p>

---

### 💻 Executar Localmente

Clone o repositório:

```bash
git clone https://github.com/marcelogomesdev/KMLucrativo-2.0.git
```

Entre na pasta do projeto:

```bash
cd KMLucrativo-2.0
```

O projeto pode ser aberto diretamente pelo arquivo:

```text
index.html
```

Também é possível iniciar um servidor HTTP local:

```bash
python -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```

---

### 📦 Gerar o Bundle de Produção

Após alterar qualquer módulo dentro da pasta `js/`, regenere o bundle de produção:

```bash
node tools/build-bundle.mjs
```

## 🔒 Dados e Privacidade

Todos os dados inseridos no KM Lucrativo são armazenados exclusivamente no **LocalStorage** do navegador.

Isso significa que:

* Nenhuma informação financeira é enviada para servidores externos;
* Não é necessário criar conta;
* Não existe coleta automática de dados pessoais;
* Os registros permanecem armazenados no dispositivo utilizado;
* Limpar os dados do navegador pode remover as informações salvas;
* O backup em JSON pode ser utilizado para preservar e restaurar os dados.
